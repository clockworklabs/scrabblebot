# Scrabblebot ideas

## Tournament

- Best of 3 finals. Today the final is three games decided by total score,
  though the README already calls it best-of-3.
- Better tournament entry process.
- Clearer tournament rules.
- Clearer terminology that the matches were practice matches, and when the
  tournament starts.
- When the tournament starts, just go right into the match. It's the only match
  we want to look at.
- Better Swiss round visualization, and a way to watch statistics across all
  matches.
- Not all the Swiss round matches could be seen after round 1. They may have
  been cut off.

## Watching

- Presentation mode (make it really big).
- An actual Scrabble board, for better visualization, with colors for the
  different bots.
- More and better visual fanfare.

## Game

- Variables to change the meta every hackathon.
- Better performance for normal gameplay.
- Local network, if possible.
